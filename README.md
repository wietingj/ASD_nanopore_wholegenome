# ASD_nanopore_wholegenome
Analysis scripts for Wieting J, et al. *Long-Read Nanopore Sequencing of Autism Susceptibility Genes: An Exploratory Study in Adults with Autism Spectrum Disorder.* Whole-genome nanopore sequencing (ONT R10.4.1, PromethION) of ASD and neurotypical controls (NC). Basecalling, QC, differential methylation and SV analysis.
